### Task-02: Titanic Dataset – Exploratory Data Analysis

Internship: Data Science Internship – Prodigy InfoTech

---

### Objective
To perform basic data cleaning and exploratory data analysis (EDA) on the Titanic dataset and identify simple patterns related to passenger survival.

---

### Dataset
Source: Titanic Dataset (Kaggle)

Description:
The dataset contains information about passengers such as age, gender, ticket class, and survival status.

---

### Data Cleaning
- Dropped the Cabin column due to excessive missing values.
- Filled missing Age values using the median.
- Filled missing Embarked values using the most frequent category.

---

### Exploratory Data Analysis
The following analyses were performed:
- Survival count of passengers.
- Survival rate comparison based on gender.
- Distribution of passenger ages using a histogram.

---

### Observations
- More passengers did not survive than survived.
- Female passengers had a higher survival rate than male passengers.
- Most passengers were young to middle-aged adults.

---

### Conclusion
This exploratory analysis highlights basic survival patterns in the Titanic dataset and demonstrates the use of simple data cleaning and visualization techniques for understanding relationships in data.
